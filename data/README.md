# Data — what is tracked, what is not

The repository includes **every light input file the notebooks read directly**. The large
matrices are excluded from version control (see `.gitignore`) and must be re-downloaded or
regenerated. No controlled-access data are included.

### Why the compound names are frozen

`chemicals/compound_names.csv` is **tracked on purpose**. It is the InChIKey → name lookup
used for figure axis labels, and it is not re-fetched on every run: PubChem reorders its
synonym lists over time. Today the first synonym returned for ibuprofen is the CAS number
58560-75-1, and for equol 531-95-3, where both returned the common name when the article
was prepared. Axis labels that depend on a live database are not reproducible, so the
lookup is frozen here and PubChem is queried only for InChIKeys the table does not cover.

the versioned original.

## Access and licences

- **LINCS / CMap 2020**: open access, CLUE.io and GEO.
- **TCGA-BRCA**: expression and phenotype data from the **open-access** tier via UCSC
  Xena. No controlled-access TCGA data (raw sequence, germline genotypes) are used or
  redistributed here.
- **GTEx**: open-access summary data (GTEx portal / UCSC Xena). No protected GTEx data
  (dbGaP) are used.
- **Chemical lists**: IARC Monographs, DEDuCT, TEDX — all public.
